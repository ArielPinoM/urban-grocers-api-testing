## BR-17
POST ```/api/v1/kits/:id/products``` returns 500 Internal Server Error when "id" is valid and "quantity" is a string value in the request body while adding products to a kit.

## Preconditions
1. The warehouse system must be active.
2. Create a kit named "TestKit".
3. Search for the kit named "TestKit".
4. Copy the kit "id".

## Test Data
Path params: id = "TestKit" id
```json
{
  "productsList": [
    {
      "id": 1,
      "quantity": "string"
    }
  ]
}
```

### Steps to Reproduce
1. Select the POST method and make a request to: URL + /api/v1/kits/:id/products
2. Send a request using the "TestKit" id in Path Variables, id = 1 and quantity = "string" in the request body.

### Expected Result
* A 400 Bad Request status code is returned in the response.
* "message": "invalid input syntax for type integer:  ..."
* The product is not added to the kit.

### Actual Result
* A 500 Internal Server Error status code is returned in the response.
* "message": "input type syntax for type integer: \"0string\""
* The product is not added to the kit.
