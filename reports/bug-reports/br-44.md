## BR-44
POST ```/order-and-go/v1/delivery``` returns 200 OK when sending a request omitting "productsWeight" field.

## Preconditions
1. The warehouse system must be active.

## Test Data
```json
{
    "deliveryTime": 15,
    "productsCount": 4
}
```

### Steps to Reproduce
1. Select the POST method.
2. Enter the URL + /order-and-go/v1/delivery.
3. Add the test data to the request body.
4. Send the request.

### Expected Result
* A 400 Bad Request status code is returned.
* "message": "productsWeight is required".

### Actual Result
* A 200 OK status code is returned.
